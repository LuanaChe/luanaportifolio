# Luana Che — Portfólio de Videomaker

Site-portfólio em página única (HTML, CSS e JavaScript puros, sem dependências).

## Como editar
Abra `index.html` e procure o bloco `const SITE = { ... }` no início do `<script>`.
Lá ficam vídeos, fotos, textos, projetos, depoimentos, links e contatos.
Vídeos e fotos ficam na pasta `media/` (vídeos em `.mp4` H.264).

## Como ver
Abra o `index.html` no navegador, ou publique com GitHub Pages
(Settings → Pages → Deploy from a branch → `main` / `/ (root)`).
